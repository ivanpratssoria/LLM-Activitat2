Introduccio a la programacio

Que es la programacio?

La programacio es el proces de crear instruccions que un ordinador pot interpretar i executar. Aquestes instruccions permeten crear programes, pagines web, aplicacions i moltes altres eines.

Existeixen molts llenguatges de programacio diferents. Alguns dels mes coneguts son Python, Java, JavaScript i C++.

El llenguatge Python

Python es un llenguatge de programacio molt utilitzat per la seva sintaxi senzilla. Es fa servir en desenvolupament web, automatitzacio, analisi de dades i intel.ligencia artificial.

Exemple de codi Python

El seguent exemple mostra un programa molt senzill escrit en Python: 

nom = "Ivan"

for i in range(3):
    print("Hola", nom)
